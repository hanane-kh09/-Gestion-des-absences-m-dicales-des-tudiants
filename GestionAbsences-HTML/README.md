# 🏥 Gestion des Absences Médicales
## Spring Boot + React CDN (sans Node.js !)

---

## ⚡ Lancement — 2 étapes seulement

### 1. Backend Spring Boot (IntelliJ)
- Ouvrir le dossier `backend/` dans IntelliJ
- S'assurer que MySQL (XAMPP) est démarré
- Lancer `GestionAbsencesApplication.java` ▶️
- ✅ Backend sur http://localhost:8080

### 2. Frontend HTML (double-clic !)
- Ouvrir `frontend/index.html` dans votre navigateur
- Ou clic droit → "Ouvrir avec" → Chrome/Firefox/Edge
- ✅ Application prête !
